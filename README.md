# Calculatrice Scientifique Interactive 🔥

Une calculatrice moderne développée en **HTML, CSS et JavaScript**, avec un design néon orange et des fonctionnalités avancées.

## ✨ Fonctionnalités
- Opérations de base : addition, soustraction, multiplication, division
- Fonctions scientifiques : sin, cos, tan, log, racine carrée, puissance, inverse, pourcentage
- Graphes dynamiques avec **Chart.js**
- Commandes vocales 🎤 (reconnaissance vocale intégrée)
- Design responsive (PC 💻 et mobile 📱)
- Effets visuels modernes : ombres, halo lumineux orange, animations au survol
